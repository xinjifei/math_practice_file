# 第 29 天验收标准

## 体系定位
- 所处阶段：线性代数基础（Day 24–39，共 16 天），今天 6/16，处于中段。
- 今天在这个阶段的角色：Day 24–28 建好了「向量 → 矩阵 = 变换」这条链；今天把这根链的最后一个动作接上——**多个变换怎么叠加**。这是从「单个变换」跨到「变换的组合」的关键一跃。
- 和目标的关系：三种核心能力里的**技术判断力**。矩阵乘法不是背「行×列」规则，而是理解「复合变换」这件事本身——它直接决定你后面能不能看懂 Attention 的内部（Q×Kᵀ×V 三个矩阵连乘），以及能不能一眼判断「这个顺序对不对」。

## AI 分界线
- **归你（必须长在脑子里）**：矩阵乘法 = 变换的叠加；顺序决定含义（不可交换）；结合律意味着「先合成再作用」等价于「分步作用」。
- **可外包（概念要知道、实现交给 AI）**：具体矩阵的逐元素「行×列」手算、numpy 的 `@` 语法、矩阵维度的逐项检查。这些是操作记忆——知道概念、交给 numpy 就行。
