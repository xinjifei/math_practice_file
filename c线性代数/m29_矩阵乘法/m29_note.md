# 矩阵乘法
> 进一步的了解矩阵乘法的性质
## 矩阵行列不相等
- 矩阵行列数不相等，无法相乘。大部分情况无法交换顺序
## 叠加
> 当需要对向量进行多轮变换（多次矩阵乘法）时，把这种多次变化打包起来
```
#目的：让向量按照 A、B的顺序变形
#正常思路：（依次变换）
B(A@v)
#打包（叠加）思路
(B@A)v
#这里越靠右的矩阵在‘变换顺序’上越靠前，比较反直觉
```
## 结合律
> 矩阵乘法的结合律性质
$$
A(BC) = (AB)C
$$
## 大部分情况不满足交换律
- 后者的变换建立在前者之上，前者有可能会影响后者变换的方向
