# m34 embedding
> 把人类的语言变成计算机的语言（向量）
## embedding是什么
> ‘人类文字 ←→ 向量’ 翻译器
- m24向量了解了‘向量’是怎么描述语义的。但是在实际应用中有一个问题：
- 现实中词汇很多，要清楚的标记出每个维度的定义以及对每个token进行定义没法像 m24一样手动标注
    - embedding中的向量库由‘训练’自动完成上述操作。训练的目的就是让语义相近的token位置也相近

## 余弦相似度
> 量化词向量的‘相似度’
- m27_向量点积余弦相似度学过怎么通过算法进行对比相似度
```
总结一下那天的算法得到大概过程
方向相似 → 余弦值大 → 相似度大
```
## 举例
> 带入具体的例子
- 为什么"新能源汽车"和"动力电池"相似度高？  
简单来说是因为它们的语义比较接近。具体这个相近是由训练定义并由余弦相似度量化的，在训练中这两个 短语/短语中的词 经常一起出现，根据这个判断它们的语义相近
- 相比之下‘白酒消费’与上面两个短语的语义相似度就会低很多，原因与前面两个词在语义上相近的原因相反。
- 但是这里的‘相近’是相对的。就像在这个例子里面，三个短语都是‘名词’，有很多短语在其他维度上和它们不相近，比如‘动词’‘蓄势待发’
