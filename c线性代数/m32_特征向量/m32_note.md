# m32 特征向量特征值
> PCA降维的基础数学概念
$$
Av = \lambda v
$$
*A=矩阵，$\lambda$=特征值，v=特征向量*
## 特征向量
- 当向量经过与一个方阵的相乘（线性变换）后，它一般会改变其方向与长度。但是有时不会，有的向量在经过一个方阵的线性变换后依然与变换前共线。对于这样的的向量我们将其称之为：一个矩阵的‘特征向量’
- 同一个矩阵所拥有的特征向量数量不一定只有一个  
举例：
```
矩阵A=
[
    [3,1],
    [0,2]
]
```
- 矩阵A就有两个特征向量[1,0][-1,1]
## 特征值
- 与特征向量共线的向量，被拉伸后模长的倍数
- 一个矩阵所拥有的特征值的数量取决于其所拥有的特征向量数量。  
比如矩阵A所拥有的两个特征向量方向的向量的模长经过线性变换后分别会被增加为原来的3倍以及2倍，即：矩阵A的两个‘特征值’分别为 3 以及 2

## PCA降维
- PCA降维会将数据压缩至数据的协方差矩阵的特征向量方向。而降维后的数据的方差的大小与协方差矩阵的特征值有绝对关系（具体关系不明）。
- 根据PCA降维的核心思想，降维后尽量保持数据的原始特征。用数学的语言来说就是降维后的数据的方差要尽可能的大  
所以为了使更少的维度得以储存尽可能多的的原始特征：降维时优先选择特征值较大的几个方向。
