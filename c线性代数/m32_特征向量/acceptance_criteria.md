# 第 32 天验收标准

## 体系定位
- 线性代数基础模块，pos 9/16。模块主线：向量(24-27) → 矩阵(28-30) → 缓冲(31) → **特征向量/特征值(32)** → PCA/Embedding/Softmax/梯度下降/熵(33-38) → 复习(39)。
- 今天是这个模块的**转折点**：前面把矩阵理解成"变换机器"（怎么把向量转来转去），今天第一次看矩阵的"内在结构"——哪些方向是它自己不变的方向。
- 能力拼图：**技术判断力**。不是记住 `np.linalg.eig` 怎么调，而是建立"为什么降维要选这些方向"的数学直觉——这个直觉换到任何"主成分/主方向/重要性排序"场景都保值。

## AI 分界线
- **归你（必须长在脑子里）**：特征向量/特征值的几何直觉（方向不变 vs 长度缩放）；为什么特征值大 = 方向重要；PCA 为什么选特征值大的方向。
- **可外包（概念要知道、实现交给 AI）**：`np.linalg.eig` 的调用语法；特征分解的算法（QR 迭代等，纯计算）。

## 硬线（不过不能结束）
- [ ] 能口述：特征向量 = 矩阵作用下**方向不变**的向量，特征值 = 长度变化的倍数。并能用一个具体例子说清"普通向量方向变、特征向量方向不变"。
- [ ] 能解释为什么 PCA 选特征值大的方向（特征值大 = 该方向承载的方差/信息更多 → 保留最重要的几个、扔掉不重要的）。
- [ ] 运行 `np.linalg.eig` 后，能指认输出里哪部分是特征值、哪部分是特征向量，并验证 `A @ v ≈ λ * v`。
