## AI 分界线
- **归你（必须长在脑子里）**：
  - 梯度 = 曲线在**某一点**上的斜率（一维就是一个带正负号的数）——不是新东西，是把 Day 3 的"直线斜率"扩到"曲线上的一点"
  - 梯度 = 损失**上升**最快的方向；梯度下降 = 朝反方向走一小步 → 重复
  - 学习率 = 步长，决定这一步迈多远（不是"精度"、不是"随机度"）
  - 损失函数 = "离目标有多远"的打分器；训练 = 把这个分数变小
  - 把"模型训练 / 调参 / loss 不降"翻译成：参数 ← 参数 - lr × 梯度
- **可外包（概念要知道、实现交给 AI）**：
  - 具体函数的梯度怎么求（求导、链式法则）——教材明确说了不需要
  - PyTorch autograd 自动求导、`loss.backward()` 怎么写
  - SGD / Momentum / Adam 各种变体的实现细节（知道存在即可）
