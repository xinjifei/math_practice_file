## 硬线1：PCA 核心思想

**1. 用一句话说清楚：PCA 找的"第一主成分"是什么方向？为什么偏偏是它？**

```
降维时能承载最多信息量（方差最大）的数轴，方向是数据协方差矩阵的特征向量中最大的那个。因为相比其他的方向其投影后承载的信息量更多
```

**2. 1000 只股票 × 1000 个特征，PCA 之后通常变成几个主成分？这背后默认了什么假设？**

```
经过实操，发现42个股票 * 240个‘特性’，PCA 之后前三个主要成分解释37.5%的方差，印证了这些股票之间的涨跌关系难以被3维概括
但是题目中的特殊情况则验证了这1000个特征高度相关，所以可以用3维表示大部分方差，而今天进行的这个实验证伪了。所以题目的假设被证伪
```

**3. "主成分"和 Day 32 学的"特征向量/特征值"是什么关系？用你自己的话连起来。**

```
主成分向量是数据的协方差矩阵的特征向量，在这其中特征值最大的能承载最多的信息
```

## 硬线2：为什么降维有用

**4. 为什么"1000 维"人脑无法理解？降维到底帮我们解决了什么具体问题？**

```
人脑生来就是为了处理3维的事物，没有办法理解。对于数据分析，降维可以把数据之间的关系用更少的维度描述，迎合人类的理解力
```

**5. 一个 PCA 结果告诉你"前 3 个主成分解释了 85% 的方差"——这句话翻译成人话是什么意思？你会怎么用它做决策？**

```
翻译成人话是这三个成分承载着85%的信息，剩下的一堆维度只能说明15%。在量化分析场景中我会对这3个维度为对象进行研究、操作，而非十几个
```

**6. 降维会"丢信息"。为什么说 PCA 丢的信息"最少"？它凭什么保证这一点？**

```
凭这个算法降维后的方差最大，用除了主成分这个方向的方向进行降维方差更小
```

## 硬线3：explained_variance_ratio_

**7. `explained_variance_ratio_` 这个数组的每个元素代表什么？所有元素加起来等于多少？**

```
代表每个成分分别解释了百分之多少的方差（浮点），和等于1
```

**8. 你拿到 `[0.6, 0.25, 0.1, 0.05]`，如果要降维到"保留 85% 信息"，你选几维？为什么？**

```
两个维度，因为前两个成分解释大部分（85%）的信息，降维后可以在损失较少信息的前提下更方便的进行研究
```

**9. 如果第一个主成分的 explained_variance_ratio_ 接近 1.0，说明原始数据长什么样？（描述形状，不写代码）**

```
数据分布类似一条线
```
