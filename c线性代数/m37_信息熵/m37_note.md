# m37 信息熵
> 量化不确定性
## 等概率事件信息熵
- 想象2种情况
1. 抛硬币
2. 转转盘（8种可能性）

- 直觉认为后者比前者传递出的信息要多。如果用二进制来回答两个事件的结果，则
1. 1 = 正，0 = 反
2. 1 = 数字0，1 = 数字二...111 = 数字八
- 发现直觉是对的，想要通过二进制传递出后者的结果需要3位。而这个‘位’数，可以通过这样的方式得出
```
# 默认对数底数为2
log(N) #N = 事件的结果数
```
- 印证这个算法
1. log(2) = 1
2. log(8) = 3

> 因此对于等概率事件，它所蕴含的信息量，也就是‘信息熵’就等于 log(N)

## 不等概率事件信息熵
- 对于大多数实际情况，事件结果大多呈不等概率
- 可以通过思路：不等概率事件是由各种等概率事件组成的，得出下面的公式
$$
H = -\sum_{i=1}^n p_i \log_2 p_i
$$
*p = 等概率事件发生在这个不等概率事件中的概率*

含义：
> 使用一个不等概率事件所拆分出来的等概率事件，按各自出现的概率做加权平均

## 计算
> 观察各种不等概率事件的信息熵
- 事件：投三种“作弊硬币”（两面出现的概率不相等）；所蕴含的信息熵下面的小数等于 p_i
    1. 0.5，0.5
    2. 0.7，0.3
    3. 0.9，0.1
    4. 1，0(只能抛出一面)

- 分别计算它们的信息熵

## 链接ai
> ai的输出概率概率分布的信息熵
- 单步解码输出的经过softmax的概率分布向量中的每一项，可以看作模型对下一个token出现的肯定性系数。越高代表他越确定，越低越不确定
- 这个向量在画出来之后应该能得出一个概率分布，这个分布越集中，代表模型对某几个token很确定，反之代表他很犹豫。
- 接上上面的‘思考’，分布越集中，信息熵越低，反之越高。
> 得出结论：单步解码得出的概率分布的信息熵越大，表示模型在这次单步解码中越犹豫，越小代表越坚定
