- 今天的概念在这个阶段的角色：**打分器的第一块砖**。熵回答的是"一个概率分布有多难猜"。往上接：m38 交叉熵 = 用真实分布去称量预测分布的意外程度 = 真正的损失函数，那个 `log` 就是从今天这个公式来的；m39 全景复习要把整条链拉直。所以熵不是孤立知识点，是 loss 公式的前半截。
- 和目标的关系：**技术判断力**。"模型很确定"、"模型在瞎猜"、"loss 降了"——这些话背后的量就是熵。换到任何领域都成立：只要你在处理概率和不确定性，熵就是那把尺子。

## AI 分界线
- **归你（必须长在脑子里）**：
  - 熵衡量的是**不确定性 / 意外程度**——不是概率本身，是"这个分布有多难猜"
  - 两个锚点及原因：确定事件（某一类 p=1）→ 熵 = 0（毫无悬念，称不出意外）；均匀分布 → 熵最大（一样可能，最难猜）
  - **方向的判断力**：越接近均匀 → 熵越大；越集中 → 熵越小。给两个分布能直接说谁大谁小，不用算
  - 熵的上限由**类别数**决定：N 类均匀时取到 log N。所以"熵 = 1.2"单独一个数没意义，得知道是几分类
  - LLM 输出层的 entropy 低 = 模型很确定；高 = 模型在犹豫
- **可外包（概念要知道、实现交给 AI）**：
  - 具体实现里的坑（`0·log0` 约定为 0、怎么在 numpy 里避开 `np.log(0) = -inf`）
  - `scipy.stats.entropy` 这类现成函数怎么调
  - log 的底数选谁（2 = bit、e = nat、10 = dit）——只差一个常数倍，趋势和判断完全一样
