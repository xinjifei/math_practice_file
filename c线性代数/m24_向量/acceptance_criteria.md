# 第 24 天验收标准

## 体系定位
- **所处阶段**：线性代数基础模块，第 1/16 天。这是整个模块的**地基日**——后续 15 天全部建立在"向量 = 空间中的箭头"这一核心直觉上。
- **今天这个概念的角色**：向量是整个 AI 世界的字母表。Embedding、Attention、梯度——所有这些操作的对象都是向量。今天不是学一个数学概念，而是在学 AI 的底层语言。
- **和目标的关系**：三种核心能力中，今天主要积累**技术判断力**——建立"数据结构的列表"和"几何空间的箭头"之间的双重视角。这个视角切换能力直接决定后续所有线性代数概念的学习深度。

## AI 分界线
- **归你（必须长在脑子里）**：
  - "向量 = 列表 + 空间中的箭头"这个双重视角——看到 `[3, 2]` 脑中出现一支从原点射向 (3,2) 的箭
  - 向量长度的几何含义：从原点到箭头的距离
  - 为什么 Embedding 可以看成向量：因为向量有运算——加减（方向变化）、比较（方向接近 = 语义接近）
- **可外包（概念要知道、实现交给 AI）**：
  - `plt.quiver()` 的具体参数语法——`angles='xy', scale_units='xy', scale=1` 这个固定写法先记住，不深究 matplotlib 内部坐标变换
  - `np.sqrt()` / `np.linalg.norm()` 的具体调用——这是操作记忆，不是判断力

## 硬线（不过不能结束）
- [ ] **口述：向量 = Python 列表 + 空间中的箭头**。用自己的话说出"列表 [x, y] 同时也是平面上从原点指向 (x,y) 的一支箭，有方向和长度"。不能只背定义，要能指着自己画的图说"这个箭头从哪到哪、方向朝哪"（依据：hardAfter 标记 Day 25-28 全部建立在这个双重视角上——向量加减的几何含义、线性组合的"到达所有位置"、点积的方向相关、矩阵变换都需要先理解"向量是箭头"）
- [ ] **手算向量长度 √(x²+y²) 且理解几何含义**。对任意 2D 向量能算出长度，能说出"长度 = 箭头的长短 = 从原点到箭尖的距离"（依据：hardAfter 标记 Day 27 点积公式 `|v||w|cos(θ)` 直接使用向量长度，长度概念不过关则点积塌方）
