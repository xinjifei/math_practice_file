# m30 转置矩阵
> 把矩阵的‘行’变成‘列‘。在attention中用于计算各token之间的语义关系相似度
## Q×Kᵀ
Q矩阵为‘查询矩阵’，K矩阵为‘键矩阵’。  
将K转置后相乘后得到新矩阵，矩阵中的每个值代表各个token间的语义关系相似度
```
# 举例
K = 
[
    [1, 2],
    [3, 4],
    [5, 6]
]
# 比如现在每行是一个token（向量），列是维度
K^T = 
[
    [1, 3, 5],
    [2, 4, 6]
]
# 转置后（矩阵沿 左上右下 对角线做转置），列变成一个token，行是维度
```
## 原理
- 在m29中有提到‘矩阵行列数不行等无法相乘’（还有图解），在这里也同样适用。  
比如有两个矩阵
```
A = 
[
    [1, 2],
    [3, 4],
    [5, 6]
]
B = 
[
    [1, 2],
    [3, 4],
    [5, 6]
]
前者列数为2，后者行数为3。所以它们除非是方阵，否则必须要进行转置才能相乘
```
> 思考：对比相似度的本质在于token之间进行点积，矩阵乘法的规则是‘行乘列’如果不进行转置就变成一个token和其他所有token的同一个维度进行点积，没有任何意义。所以需要转置  
> 上面说的是‘如果没转置相乘会怎么样’，但是在实际的应用当中矩阵行列数相等的情况（方阵）几乎不会出现，所以在这一步就卡住，无法相乘

## 单次token间计算示例（点积）
```
i = Q的一行（对应一个token）
j = K^t的一列，同样对应一个token
# 计算中i = j（比如第第一行对应第一列）
i_0*j_0 + i_1*j_1 ... i_n*j_n
```
