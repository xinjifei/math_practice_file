## 概念接口
- 这次不直接串概念本身，而是把整个ai的节点列出来往里填学过的知识点
### ai工作流节点概览
```
token —— embedding —— transformer —— softmax —— cross entropy —— gradient descent
```

### 填知识点
1. token（入 = 自然语言，出 = token）
    > 编码自然语言为计算机语言
2. embedding （入 = token，出 = 向量）
    > 一张表，它将token转化为真正的数字 —— 向量
    - 特征向量
    - PCA降维
    - Embedding
3. transformer（入 = 向量，出 = logits向量）
    > 核心算法，输出下一个token出现可能性的分数
    - 转置矩阵
    - 矩阵乘法
    - attention
4. softmax（入 = logits向量，出 = 概率分布）
    > 把机器预测的结果向量（logits），用softmax函数标准化成概率分布
    - softmax
5. cross entropy（入 = 预测值&实际值，出 = 交叉熵）
    > 进入机器训练范畴。这一步是使用交叉熵函数对模型的输出进行打分
    - 信息熵
    - 交叉熵
6. gradient descent（入 = 损失函数（交叉熵函数），出 = 更新权重）
    > 使用微分的方法找到可以让损失值变小的新配置，然后使用这种新配置  
    >为什么它一定要用交叉熵来当打分器？因为这种损失函数的函数图像最为平滑，简单说就是对于微小的改动它都可以反应出来。平滑的函数图像更适合进行下降。举个反例，如果打分函数是：对了就0，错了就1。那么它的函数图像就会是割裂的阶梯式，没有梯度。没有梯度下降就无从谈起
    - 微分（c_1梯度下降专项）
    - 梯度下降

## 从零讲一个数学
- 选梯度下降，因为感觉这个相对来说在概念上比较好理解

1. 量化训练
    - 先明确训练ai的目的，训练的目的就是想要让它的输出尽可能的接近答案。但是这种想法是抽象的，量化成数字就是：训练的目的是让ai的输出与真实值的差距尽可能小
    - 这种差距被量化为“损失值”，值越大，ai错的越多，值越小，ai错的越少。很明显需要通过一些方法最小化损失值
2. 可视化函数
    - 可以想象这样一个场景：一个三维的函数图像，这个函数的z轴是损失值，另外两个轴是ai的配置参数（假设这个ai只有两个配置参数）。可以看得出来，这个函数列举出来了所有配置参数下的损失值。
    - 这个函数有个名字：损失函数。它看上去像一块起伏的山地
3. 最低点
    - 再回顾训练的目标：最小化损失值。但是这个目标只是目标，并不是真正的操作对象。现在可以明确“最小化”这个动作的操作对象是：ai的配置参数。
    - 那么什么参数下损失值最小？还是上面那个三维损失函数的例子：在损失值最低点处的xy值就是要找的目标配置。在函数图像上看就像山谷
4. 下降
    - 但是这个函数的最低点并不是这么好找，对于真正的ai，这个函数的维度可能上亿。所以只能通过另一种更硬核的方式找到最低点：随便找一个点，然后在这个点上看哪个方向是通往下面的，找到这个方向，然后迈出一步，如此往复
    - 这个方法有一个名字：“梯度下降”。
