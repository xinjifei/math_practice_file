- 今天的概念在这个阶段的角色：**m36 欠下的那个缺口，今天补上**。m36 说训练循环要转起来需要两样东西——一个**打分器**（损失函数）+ 一个**改进器**（梯度下降）。改进器当时就有了，打分器一直空着；m37 造了熵（"意外程度"的尺子），今天把尺子接到真实标签上 = **交叉熵 = 分类和 LLM 训练里真正在用的那个损失函数**。往后看：m39 全景复习要把整条链（向量 → 矩阵 → softmax → 梯度下降 → 熵 → 交叉熵）拉直。
- 和目标的关系：**技术判断力**。"模型在训练"、"loss 降不下去"、"换个损失函数"——这些话背后的量今天有了名字和形状。换到任何领域都成立：只要你要衡量"预测和真实的差距"，就需要一个对微小改进也有反馈的度量。

## AI 分界线
- **归你（必须长在脑子里）**：
  - 交叉熵 = 拿**模型的预测 q** 当尺子，去量**真实事件 p** 的意外程度；q 越贴近 p → 越小
  - 它和熵的**区别**：熵是"拿分布自己量自己"，交叉熵是"拿别人的分布量自己"；**联系**：交叉熵有个下限 `H(p,q) ≥ H(p)`，q 完全等于 p 时才取等（多出来的那截代价叫 KL 散度）
  - **为什么不用准确率**：准确率只看最后判对没判对，是台阶式的；交叉熵看的是概率本身，微小改进也能给反馈
  - **one-hot 退化**：真实标签是 `[1,0,0]` 时求和只剩一项，交叉熵 = `-log(q_正确类)` ——这是看懂 LLM 训练 loss 的钥匙
- **可外包（概念要知道、实现交给 AI）**：
  - KL 散度的公式和推导（教材明确说了不需要）
  - `nn.CrossEntropyLoss` 这类现成实现的调用细节（它把 softmax 和取 log 合并起来算，数值更稳；知道有这回事即可）
  - 交叉熵对参数的梯度推导、log 底数的选择（换底只差常数倍，用 2 就是 bit）
