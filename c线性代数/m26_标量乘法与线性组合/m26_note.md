# m26_标量乘法与线性组合
> 这是后续embedding等概念的基础
## 标量乘法
> 通过引入一个系数来改变向量的模长甚至朝向  
```python
c = coefficient(系数)
v = vector(向量)

def 标量乘法(c:float, v:list) -> list:
    result =[c*x for x in v]
    return result
```

## 线性组合
*图解：./m26_script_0.py*
> 两个向量经过标量乘法改变模长，这两个向量的和被称为线性组合

```python
v_1 = vector_1
v_2 = vector_2
c_1 = coefficient_1
c_2 = coefficient_2

def 线性组合(v_1:list, v_2:list,
            c_1:float, c_2:float
        ) ->list:
    result = c_1*v_1 + c_2*v_2 # 这里的相乘就是标量乘法
    return result
```

> 最后得到的新向量的取值范围的重要因素之一‘共线’或‘线性相关’，以及‘非共线’或‘线性无关’（后面全都用线性相关这种叫法）

### 线性 相关/不相关 举例
*图解：./m26_script_0.py*
> 从几何意义上来看，线性相关表现为‘在一条直线上’，不相关则表现为‘不在一条直线上’

### 思考
*图解：./demo_线性组合.py*
> 根据线性相关以及线性组合的几何意义可以知道，不管在进行计算的过程中如何改变系数都是在改变两个向量的共线方向的模长，而相加的结果也必然共线，换言之：  
> 二维的线性组合如果两个向量 线性相关，那么它所能够‘张成（span）’的范围就是一条线，反之不相关的张成范围则是整个面
