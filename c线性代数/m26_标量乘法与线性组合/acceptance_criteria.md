# 第 26 天验收标准

## 体系定位
- **所处阶段**：线性代数基础模块第 3/16 天，模块刚开头。前面铺了「向量是什么」（Day 24）和「向量加减」（Day 25），今天进入本模块第一个核心概念：**线性组合 / 张成**。
- **这个概念的角色**：它是整条能力链的地基。后面「矩阵乘法 = 列的线性组合」「特征向量」「PCA / 降维」「Embedding」全部站在「向量张成空间」这个直觉上。今天没建立这个直觉，后面全塌。
- **和目标的关系**：训练的是**技术判断力**——把一个向量想象成「能到达的范围」，而不是一个孤立的箭头。这是后面理解「为什么降维能保留信息」「为什么 Embedding 让相似语义聚在一起」的底层视角。
