# m22 多元线性回归
> 真实的世界中影响因变量（y）的自变量（x）大部分情况不止一个。所以来学多元线性回归

## 多元线性回归y_hat计算公式
> 算法需要求出其中的b值以及a值使拟合结果的r**2最大
### 赋值：
```
a = 截距
b_i = 在其他自变量不变时单因子斜率
x_i = 单因子值
```
**y_hat == a + SIGMA(b_i * x_i)**

## 原理
> 通过引用多个因子的方法拟合的y_hat值更加接近实际y值  
### 举例（蜜雪冰城饮品销量）
1. 单元线性回归
    - 自变量（单个）
        - 街道人流量
    - 因变量
        - 销量
2. 多元线性回归
    - 自变量（多个）
        - 街道人流量
        - 天气温度
        - 季节
        - 选址
    - 因变量
        - 销量
> 总结：
> 可以很直观的发现用下面一种判断方法可以得出更准确的回归线
