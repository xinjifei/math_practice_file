## r ** 2
> 这个就是用来量化拟合程度的值
### 计算
```python
data = 数据（list）

#先算用来量化波动的两个值
## 总变异（y值的方差）
def 方差(data:list) -> float:
总变异 = 方差(data)
## 残差（y值的方差，但是减去的不是均值而是减去回归线的y值）
def 残差(data:list) -> float:
残差 = 残差(data)

#计算r ** 2
def r方calc(
    总变异:float, 
    残差:float
    ) -> float
    ## 重点计算
    r方 = 1 - 残差 / 总变异
    return r方

r方 = r方calc(残差, 总变异)

```
> 思考：这里比的就是和数据原本的离散程度相比，数据相对于回归线——也就是残差 的离散程度。分子是1-残差，残差越小分子越大（因为分子是 1-残差），分子越大r方越大。

## 判断
- r方 = 0 = 这个回归线的解释效果和均线一样
- r方 = 0.05 几乎什么都没有解释
- r方 = 0.8 = 剩下20%没解释
- r方 = 1 = 完全拟合，正常情况下基本上不会这样，有可能是过拟合
