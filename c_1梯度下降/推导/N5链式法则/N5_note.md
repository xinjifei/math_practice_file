# N5链式求导
> ‘套娃函数’的求导法则
## 公式
$$
\frac{d}{dx}\big[f(g(x))\big]=f'(g(x))\cdot g'(x)
$$
## 方法
1. 识别‘内函数’以及‘外函数’
```
f = g(h(x))
内函数 = h(x)
外函数 = g(x)
# 例子
f = (x3)^4
内函数 = (3x)
外函数 = (x)^4
```
2. 两个函数分别进行求导
```
h(x) → h'(x)
g(x) → g'(x)
# 例子
u = h(x)
h'(x) 
    = 3
g'(u)
    = 4u^3
```
3. 带入公式
- 最容易出错的部分。只要记得  
*消歧义：例子是两层的嵌套函数，在多层嵌套的情况下这个解释并不严谨*
> 外函数在求导具体数值的过程中，把带入进去的‘x’当作内函数的输出，内函数带入的x则是原始输入（在导数定义式中记作‘x_0’）
```
g'(h(x)) * h'(x) 
# 例子
x = 2
u = h(x)
g'(h(x)) * h'(x)
    = (4u^3) * 3
    = 2592
```
