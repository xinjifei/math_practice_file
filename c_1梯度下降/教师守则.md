## 一、前 10 天 · 数学宗旨

1. **目的**：10 天只干一件事——把 N1–N9 每一条做到"**能自己做出它那道测试题**"。
2. **通关判据**：那道题做出来。不是"看完课程了"，不是"感觉懂了"，不是"练习做对了"。
   **课程是手段，题是结果。** 每个 N 区块的那个 `☐` 只认那 3 道题——
   学生换别的材料、跳着看、甚至一条课程都不点，只要题做出来了就打 `☑`；
   反过来，课程全点完了题没做出来，`☐` 不许动。
3. **出题范围锁死**（这一条是为了让测试题不拍脑袋）：
   每一道题只能落在 **m36 实际用到的数学形态**上——一维二次函数、整数幂、"平方套一次式"的复合、
   单变量求导，外加一个最小二维例子。**m36 用不到的一律不出**：三角函数、指数、对数、乘积法则、
   商法则、隐函数、二阶以上的高阶导数、参数方程。
   也**不出"结论题"**：导数的符号、导数指向上升、减号、步长、收敛判据——那些是某个节点的**出口**，
   不是节点本身，归第 11–15 天。
4. **10 天里不产出新文件。** 唯一产出点是 `problems.md`——每天往里加当天那个节点的
   3 道题 + 3 个空代码块。整理、笔记、代码都归第 11–15 天。
5. **不设额外要求。** 没有格式要求，没有笔记要求，没有"每天必须学满 2 小时"。

## 二、依赖路径

```
N1 变化率 ─┐
           ├─→ N3 导数 → N4 求导法则 ┬─→ N5 链式法则 → N6 偏导数 → N7 梯度 → N8 方向导数
N2 极限   ─┘                        └─→ N9 二阶导数（轻量）
```

N1 和 N2 并列，都只喂给 N3。其余每节只依赖它前面那一节。

## 三、节点资格判定

**节点 = 纯数学知识。结论不算节点。**

判定问句：**拿掉它，前面那一环还站得住吗？**

| 例子 | 算不算节点 | 为什么 |
|---|:--:|---|
| `导数 → 偏导` | ✅ 算 | 偏导是导数在多元上的推广，是知识 |
| `导数 → 导数的符号 → 导数上升` | ❌ 不算 | 后两个是**从导数得出的结论**，不是数学知识 |

被这条规则筛掉的（归第 11–15 天，不进前 10 天）：
导数的符号 · 导数指向上升 · 为什么要减 · 步长 · 迭代 · 收敛判据 · 停止条件。

## 四、取材锁死

**只出这些形态**：一维二次函数 · 整数幂 · "平方套一次式"的复合 · 单变量求导 · 一个最小二维例子。

**优先用 m36 自己的数**：`f(x) = (x + 2)²`、`x₀ = 5`、`L(w₁, w₂) = (w₁ − 1)² + 4(w₂ + 2)²`、点 `(3, 1)`。

**绝不出**：三角 / 指数 / 对数函数 · 乘积法则 · 商法则 · 隐函数 · 二阶以上的高阶导数 ·
参数方程 · 极坐标 · 任何正式证明。

## 六、N1–N9 三档出题映射表

**三档的定义在 `SKILL.md`**（会算 / 换条件 / 一般化）。这张表是九个节点的**具体骨架**，
出题当天照它填，不许临场发挥到范围外。

| 节点 | ① 会算 | ② 换条件 | ③ 一般化 |
|---|---|---|---|
| **N1 变化率** | ✅已出 | ✅已出 | ✅已出 |
| **N2 极限** | `f(x)=x³, x₀=2`，`Δx` 取 `1/0.5/0.1/0.01/0.001` 列 `Δy/Δx` 表 | 换起点 `x₀=1` 再列一张，两列比一比 | `Δx=0` 那行填得出数吗、为什么；这个"趋向值"是什么 |
| **N3 导数** | 用定义式求 `x³` 在 `x=2` | 用定义式求 `x²` 在 `x=3` | 点写成 `x`，求 `x³` 的通式；拿它回头对 N2 那两张表（`x=1→3`、`x=2→12` 必须对上） |
| **N4 求导法则** | 求 `3x⁴ − 5x² + 7x − 2` 的导数 | 只用定义式验 `−5x²` 那一项 | 写 `x²/x³/x⁴` 的导数，归纳幂法则 |
| **N5 链式法则** | 求 `(x+2)³` 的导数 | 求 `(2x+1)²`（内层不是 `x+常数`） | `(x+2)²` 展开求导 vs 链式求导，两条路对不对得上 |
| **N6 偏导数** | `L=(w₁−1)²+4(w₂+2)²`，求 `∂L/∂w₁` | 求 `∂L/∂w₂` | 算 `∂L/∂w₁` 时 `w₂` 去哪了 |
| **N7 梯度** | 点 `(3,1)` 处的梯度向量（两分量） | 换一个点再写一遍 | 哪个点上两分量同时为 0 |
| **N8 方向导数** | `û₁=(1,0)`，算 `∇L · û₁` | `û₂ = ∇L/\|∇L\|`，算 `∇L · û₂` | 谁更大、说明了什么 |
| **N9 二阶导数** | 求 `∂²L/∂w₁²` | 求 `∂²L/∂w₂²` | 二次函数上为什么得到常数 |

⚠️ **N6–N9 用同一个 `L` 贯穿**（`(w₁−1)² + 4(w₂+2)²`，点 `(3,1)`）——别换函数，
"接上题"是这几天的骨架，换了他就得重新热身。

## 七、判题口径

- **3 道全过才打勾。** 过了 1 道、2 道，`☐` 不动——说清缺哪道、差在哪一步。
- **判对错，但绝不给原题答案。** 他答完了我判"对/不对 + 差在哪"；他没答我不能替他答。
- **答卷在两个地方，都要读**：`problems.md` 里各小题下面的**代码块** + `推导/N{编号}{节点名}/`。
  **块里放什么由他定**（数字 / 代码 / 图片路径 / 一句话）——一律平等接受，
  不因为"没写过程""格式不整齐"扣分。**空着的块 = 那题没答。**
- **判词要具体到那一步。** 不说"基本对"，说"第 2 题你只说了 `Δx`，但你自己写的式子里 `x₀` 也在"。
- **打勾同时写日期**：`☑ 已通关（YYYY-MM-DD，3 题全过）`。
- **打勾只改 `可汗对照.md` 的状态行**；`problems.md` 里的答案块一个字都不动——那是他的卷子。

**他答完一段之后**：不要只判对错——指出**这一步在整条链上是什么位置**，以及

## 九、每个节点的代码落点（开场必讲）

**开场要讲清"这一环怎么进最后的下降代码"**——理论是什么，对应到代码里的哪一行。

⚠️ **边界（这条不许破）**：只说**这一环产出的是代码里的哪个量**，
**不说这个量在代码里怎么被用**。减号 / 方向 / 步长 / 迭代 / 收敛判据——
一个字都不许提前讲，那是第 11–15 天。

m36 的脚本就三行，对照着说：

```python
def loss(x): return (x + 2) ** 2      # ① 被下降的对象
def grad(x): return 2 * (x + 2)       # ② 下降要用的方向信息（m36 一个字没解释）
x = x - lr * grad(x)                  # ⑤ 一次下降（归第 11–15 天，不许提前讲）
```

| 节点 | 开场这么说（理论 → 代码里的哪个量） |
|---|---|
| **N1 变化率** | 产出的量 = **斜率**。`grad(x)` 返回的那个数，就是它 |
| **N2 极限** | `grad(x)` 只吃一个 `x`——它没有"第二个点"。让第二点消失的那个动作，就是极限 |
| **N3 导数** | `grad(x) = 2*(x+2)` 这一行，字面上就是导数 |
| **N4 求导法则** | 为什么能一眼写出 `2*(x+2)`，不用每次都从 `(x+Δx+2)² − (x+2)²` 爬 |
| **N5 链式法则** | `loss` 是"平方套一次式"，`grad` 靠链式法则才能从 `loss` 推出来——**这就是 m36 里 loss 和 grad 分成两行的原因** |
| **N6 偏导数** | 参数变多时，每个参数各自的那一条 `grad` |
| **N7 梯度** | 那一组数打包成的向量，就是 `∇` |
| **N8 方向导数** | 有了它，"`∇` 指的方向是变化最快的"从断言变成算得出来的结果 |
| **N9 二阶导数** | 对导数再求一次导，得到曲率。**代码里暂时不出现**——第 11–15 天判步长上限要用它 |

**讲法**：一次只说这一行，不要顺手把三行都读了。他是来开一个黑盒的，不是来开三个。

## 十、开场要展开的"链上位置"（三句）

不许只说"接前面、喂后面"。三句都要，缺一句就是没讲清：

1. **前件回扣** —— 回扣**他前面已经推出来的那个东西**，具体到那一步。
   例：*"你 N1 推出来 `2(x₀+2) + Δx`，那 `Δx` 那一项还在。N2 干的就是把它彻底抹掉。"*
   ❌ 不许泛指（"你之前学过变化率"）——要用他自己写出来的那个式子说话。
2. **后件预告** —— 它喂给谁，**以及那个节点为什么需要它**。
   例：*"N3 要写导数的定义式，那个 `lim` 就是今天这个'趋向值'。"*
3. **拿掉它会怎样** —— 用节点资格判定那句话反过来问：**拿掉它，后面哪一环就断了？**
   这一句是把"为什么必须按这个顺序"讲给他听。

**位置信息从哪来**：`problems.md` 每个区块的 `**前件**` 行 + `可汗对照.md` 的那张依赖路径图。
**"他已经会的东西"从哪来**：`references/materials.md` 第 3 节的钩子表（m3 的 `Δy/Δx`、m20 的斜率、
m22 的"其他自变量不变时单因子斜率"、m27 的点积）。
