## demo 1（对应题 A1 · 题型：A 概念判定）

> ⚠️ 演示的是**另一个同类问题**，和题 A1 的问题不同。看方法，然后自己做题 A1。

**演示的问题**：题目 A1 问"`0/0` 为什么不是答案"。这里演示一个同类但不同的问题——**"平均变化率"里的"平均"两个字，到底"平均"在哪两个东西之间？**

### 步骤 1：把问题翻译成一个"能数"的动作

概念判断题最怕凭感觉答（"因为平均就是要平均嘛"）。先把问题改写成一个人能做到的动作：

> 数一数：式子里**有几个点**在场？

**为什么这么做**：因为"为什么"层面的问题，只要能被翻译成"数一数 / 写一写"，答案就不再靠语感，而靠你手上写出来的东西。

### 步骤 2：把式子写出来，看有几个点

取一个函数 `f`，取两个点：一个是出发点 `x₀`，另一个是"往前走一小段"之后到的点 `x₀ + Δx`。

平均变化率写成：

```
Δy      f(x₀ + Δx) − f(x₀)
———  =  ————————————————————
Δx          (x₀ + Δx) − x₀
```

记号解释（第一次出现，逐个说）：
- `Δ`：大写 delta，读作"delta"，意思是"**变化量**"（一段的差）。
- `Δy`：y 方向上的变化量，也就是"到了之后的值 − 出发时候的值"。
- `Δx`：x 方向上的变化量，也就是"走了多远"。
- `x₀`：下标那个 0 表示"**出发点**"（不是"0 这个数"）。

现在数一数：分子里 `f` 出现了**两次**，分母里 `x` 出现了**两次**——**两个点都在场**。

**为什么这么做**：把"平均"落到式子上，你才能看见它管的到底是几个点。

### 步骤 3：逆着问一句——"如果只留一个点会怎样"

假设你只想要"一个点"的信息，那就没有"另一个点"，上面式子里 `Δx` 就没了分母，分子变成 `f(x₀) − f(x₀)`。

所以：**"平均"二字本身就是"两个点都在场"的提醒**。这也是为什么今天要费劲把"另一个点"写成 `x₀ + Δx`——只有把它写成式子里的一个量，才谈得上"让它变小"。

**为什么这么做**：判定一个词有没有说清，最快的办法是"把它是靠什么成立的"拆出来看。

**结论**：题 A1 要的是另一个方向上的同一种剥法——把 `Δx = 0` 代进去，看**你手上还剩什么**。那一层留给你自己答。

## demo 2（对应题 A2 · 题型：A 概念判定）

> ⚠️ 演示的是**另两句、另一个话题**的话，和题 A2 的三句话都不同。看方法，然后自己做题 A2。

**演示的问题**：判定并改写下面两句关于**斜率**的话（它们说的是你 m20 note 里的那个"斜率"）。

- 句子甲："斜率 = 当 x 加 1，y 增加多少。"
- 句子乙："斜率就是那条线有多陡。"

### 步骤 1：先把"合格"的标准立出来

> 一句话合格不合格，不看它像不像对的，看**它能不能让你动手算出东西**。
> 能指着它写出式子的 → 合格；只能让你点头或摇头、写不出任何一行的 → 不合格。

**为什么这么做**：A 档题问的是"为什么"，但答"为什么"也得有个尺子。尺子立好，判断就不再是口味问题。

### 步骤 2：拿尺子去套句子甲

"x 加 1、y 增加多少"能直接翻成算式：`Δy / Δx`，其中 `Δx = 1`。

→ **合格**（你能照着它算出数）。但要补一句它**藏了什么**：它把 `Δx` 偷偷定成了 1，所以它说的是"**一大步（Δx = 1）上的平均**"，不是"某一点上"的。

**为什么这么做**：合格的话也可能有坑——坑不在"对不对"，在"它没说清哪一步"。

### 步骤 3：拿尺子去套句子乙

"有多陡"——量哪个量？x 走多少？没有数、没有量、没有可写的式子。

→ **不合格**。要害是：你拿着这句话，**一行式子都写不出来**，所以你没法用它算出任何一个数。

**为什么这么做**：说清"要害"而不是"不好听"，是 A 档题给分的地方。

### 步骤 4：把不合格的改写成合格的

改写句子乙：

> "在线上取两个点，写出 `Δy / Δx`（`Δx` 是这两个点在 x 方向上隔了多远）；`Δx` 取得越小，这个比值越接近这条线在这一点上的倾斜程度。"

改写后的句子里必须出现**能算的量**（`Δy`、`Δx`、两个点）。

**为什么这么做**：改写不是修饰文字，是**把堵住的那一步补回来**。

**结论**：题 A2 要的是同一把尺子，但量的是**你手上那三句话**——哪几句能让你写出式子、哪几句写不出来，由你自己判。那一层留给你自己答。

## demo 3（对应题 B1 · 题型：B 推导）

> ⚠️ 演示用的是**另一组函数和数值**：`f(x) = x³`，起点 `x₀ = 2`。和题 B1（`x²`，起点 3）不同。看方法，然后自己做题 B1。

### 步骤 1：把两个点写出来

- 出发点：`x₀ = 2`，它的函数值是 `f(2) = 2³ = 8` → 点 `(2, 8)`
- 另一个点："往前走一小段"：`2 + Δx`，它的函数值是 `f(2 + Δx) = (2 + Δx)³` → 点 `(2 + Δx, (2 + Δx)³)`

**为什么这么做**：平均变化率只能对**两个点**定义——先把这两个点摆在纸上，后面的式子才有东西可写。

### 步骤 2：写出平均变化率

```
Δy      f(2 + Δx) − f(2)     (2 + Δx)³ − 8
———  =  —————————————————  =  ——————————————
Δx           (2 + Δx) − 2            Δx
```

注意分母 `(2 + Δx) − 2` 化简就是 `Δx`——**这是"往前走一小段"这个写法的好处**：分母自动变成那个"一小段"。

**为什么这么做**：把"另一个点"写成 `x₀ + Δx` 而不是随便一个字母，就是为了让"走了多远"这个量**直接出现在分母上**。

### 步骤 3：把分子展开

先算平方：

```
(2 + Δx)² = 2·2 + 2·Δx + Δx·2 + Δx·Δx
          = 4 + 4Δx + Δx²
```

再乘一次：

```
(2 + Δx)³ = (2 + Δx)(4 + 4Δx + Δx²)
          = 2·4 + 2·4Δx + 2·Δx² + Δx·4 + Δx·4Δx + Δx·Δx²
          = 8 + 8Δx + 2Δx² + 4Δx + 4Δx² + Δx³
          = 8 + 12Δx + 6Δx² + Δx³
```

（就是把第一个括号里的每一项，分别乘第二个括号里的每一项，一条不漏地列出来再合并。）

**为什么这么做**：展开是为了让 `8` 这个"出发点的函数值"露出来——下一步要用它做减法。

### 步骤 4：做减法，再约掉 Δx

分子：

```
(2 + Δx)³ − 8 = (8 + 12Δx + 6Δx² + Δx³) − 8
              = 12Δx + 6Δx² + Δx³
```

除以 `Δx`（**每一项都含 Δx，所以每一项都能约掉一个 Δx**）：

```
12Δx + 6Δx² + Δx³
——————————————————  =  12 + 6Δx + Δx²
        Δx
```

**为什么这么做**：这一步把式子变成了"**一个不含 Δx 的部分（12）** + **还带着 Δx 的部分（6Δx 和 Δx²）**"——这正是题目 B2 要求你看清的那个形状。

**注意**：这里能约，是因为我们只是"**让 Δx 变小**"，没有让它**等于 0**。`Δx = 0` 的话，分母就是 0，约这一步根本不能做。

### 步骤 5：让 Δx 一步步变小，列张表

把 `Δx` 依次取 `1`、`0.5`、`0.1`、`0.01`，代进 `12 + 6Δx + Δx²`：

| Δx | 6Δx | Δx² | 12 + 6Δx + Δx² |
|---|---|---|---|
| 1 | 6 | 1 | **19** |
| 0.5 | 3 | 0.25 | **15.25** |
| 0.1 | 0.6 | 0.01 | **12.61** |
| 0.01 | 0.06 | 0.0001 | **12.0601** |

**为什么这么做**："趋向哪个值"这句话必须看得见——表就是把"趋向"画出来给你看的最土、也最可靠的办法。

### 步骤 6：读趋势

看表：`Δx` 从 1 掉到 0.01，那两个"还带着 Δx 的部分"（`6Δx` 和 `Δx²`）一路缩水：`6 → 0.06`、`1 → 0.0001`。

它们**都往 0 走**，所以整个式子**趋向那个不含 Δx 的 12**。

**为什么这么做**：你不需要"让 Δx 等于 0"——只要看清**哪一部分不随着 Δx 变小而变**，它就是趋向值。这里 `12` 是唯一不动的部分。

### 步骤 7：收口，写成 lim

```
              (2 + Δx)³ − 8
   lim        ————————————————  =  12
Δx → 0              Δx
```

记号解释（第一次出现）：
- `lim`：limit（极限）的缩写，意思是"**去看它趋向什么**"。
- `lim` 下面那行 `Δx → 0`：`→` 读作"趋向"，整句是"**让 Δx 变小、趋向 0**"——注意它**不是** `Δx = 0`。
- 等号右边的 `12`：是**趋向上的落点**，不是"某一行的值"。

**为什么这么做**：把"趋向"写成 `lim`，是为了以后不用每次列一张表就能说清同一件事。

## demo 4（对应题 B2 · 题型：B 推导）

> ⚠️ 演示用的是**另一个函数**：`f(x) = 1/x`，起点 `x₀ = 1`。和题 B2（`x²`，起点用字母 `x₀`）不同。看方法，然后自己做题 B2。

### 步骤 1：先把"取数版"走一遍（`x₀ = 1`）

两个点：`(1, f(1)) = (1, 1)` 和 `(1 + Δx, 1/(1 + Δx))`。

平均变化率：

```
Δy      1/(1 + Δx) − 1
———  =  ————————————————
Δx            Δx
```

**为什么这么做**：先把具体数走通，再上字母——这样字母版的每一步你都知道自己在干什么。

### 步骤 2：通分，把分子整理成一个整体

```
            1        1      1        (1 + Δx)       1 − (1 + Δx)        −Δx
1/(1+Δx) − ———  =  ——————— − ——————————————  =  ———————————————  =  ———————
            1      1 + Δx      1 + Δx              1 + Δx           1 + Δx
```

记号解释：通分就是把两项都写成分母相同的分数——这里分母都变成 `1 + Δx`。

**为什么这么做**：分子的 `Δx` 只有被整理出来，才能和分母的 `Δx` 对上、约掉。

### 步骤 3：除以 Δx，约掉

```
  −Δx/(1 + Δx)        −Δx         1            −1
———————————————  =  —————————— · ————  =  ——————————
       Δx            1 + Δx      Δx          1 + Δx
```

（除以 `Δx` 等于乘 `1/Δx`；分子里的 `Δx` 和它约掉。）

**为什么这么做**：约掉之后，分母里那个麻烦的 `0` 消失了——`Δx` 只剩一个位置（分母的 `1 + Δx`），它变小的时候看得清清楚楚。

**顺带一句**：`Δx = −1` 这一档**不能取**，因为 `1 + Δx` 会变成 0，式子在这一档没有值。这正是题 A1 说的那件事的另一副面孔。

### 步骤 4：让 Δx 变小，从**两侧**各看一眼

| Δx | 1 + Δx | −1/(1 + Δx) |
|---|---|---|
| −0.5 | 0.5 | **−2** |
| −0.1 | 0.9 | **−1.111…** |
| −0.01 | 0.99 | **−1.0101…** |
| +0.01 | 1.01 | **−0.9900…** |
| +0.1 | 1.1 | **−0.9090…** |
| +0.5 | 1.5 | **−0.6666…** |

**为什么这么做**："趋向"这个说法要站得住，得保证它**不取决于你从哪边靠近**。上半张表从左边靠近、下半张表从右边靠近——两边都往同一个数上收。

### 步骤 5：读出落点，写成 lim

```
            1/(1 + Δx) − 1
   lim      ————————————————  =  −1
Δx → 0            Δx
```

注意落点是**负数**，而且值是从两边夹过来的：从下面来的（−2、−1.11…、−1.01…，比 −1 更小）和从上面来的（−0.66…、−0.90…、−0.99…，比 −1 大）都停在 −1 上。

**为什么这么做**：落点是负的也照收——趋向值跟正负无关，只跟"哪一部分不随 Δx 变"有关。

### 步骤 6：换上字母 x₀（这就是题 B2 要的那一步）

同样的事，起点不取数，写 `x₀`：

```
Δy      1/(x₀ + Δx) − 1/x₀
———  =  ————————————————————
Δx              Δx
```

通分（公分母是 `x₀(x₀ + Δx)`）：

```
 1       1        x₀            x₀ + Δx        x₀ − (x₀ + Δx)          −Δx
————— − ————  =  ———————————— − ————————————  =  ————————————————  =  —————————————
x₀+Δx    x₀      x₀(x₀+Δx)      x₀(x₀+Δx)          x₀(x₀ + Δx)         x₀(x₀ + Δx)
```

除以 `Δx`，约掉：

```
    −Δx               1              −1
—————————————  ·  ————  =  ————————————————
x₀(x₀ + Δx)       Δx         x₀(x₀ + Δx)
```

现在看 `Δx → 0`：分母里的 `(x₀ + Δx)` 趋向 `x₀`，所以整个式子趋向

```
    −1
————————
   x₀ · x₀        （也就是 −1/x₀²）
```

**为什么这么做**：字母版和取数版**形状应该一模一样**——这一步只是把 `x₀ = 1` 换回字母。把 `x₀ = 1` 代回去：`−1/(1·1) = −1`，和步骤 5 的结果对上，说明字母版没错。

**这就是题 B2 第 4 步要做的"对账"**：取数版和字母版互相验证，错一个立刻现形。

## demo 5（对应题 C1 · 题型：C 验算）

> ⚠️ 演示用的是 **demo 3 那道题（`f(x) = x³`，起点 2）**，`Δx` 取的是**另一组数**（`0.2 / 0.05 / 0.02 / 0.005`）。和题 C1 的 `Δx` 不同。看方法，然后自己做题 C1。

### 步骤 1：把表继续往下接

demo 3 化简出来的式子是 `12 + 6Δx + Δx²`，趋向值是 `12`。现在把 `Δx` 换成更小的一组：

| Δx | 6Δx | Δx² | 式子的值 | 离 12 还差 |
|---|---|---|---|---|
| 0.2 | 1.2 | 0.04 | 13.24 | **1.24** |
| 0.05 | 0.3 | 0.0025 | 12.3025 | **0.3025** |
| 0.02 | 0.12 | 0.0004 | 12.1204 | **0.1204** |
| 0.005 | 0.03 | 0.000025 | 12.030025 | **0.030025** |

**为什么这么做**：C 档题的任务就是"接表 + 读差距"——不接表，你看不出差距是在**缩小**还是**停住了**。

### 步骤 2：读差距

差距列：`1.24 → 0.3025 → 0.1204 → 0.030025`。

- 每一档都在**缩小**（因为 `Δx` 每小一截，差距就跟着小一截）；
- 但**没有一档是 0**，而且**永远不会出现 0 这一档**——因为只要 `Δx` 还不是 0，`6Δx` 和 `Δx²` 就还不是 0。

**为什么这么做**：这一步是 C 档题真正的产出——把"趋向"和"等于"这两句话**分开**。

### 步骤 3：顺带看一眼差距的"来源"

对比 `Δx = 0.05` 那一行：差距 `0.3025`，而 `6Δx = 0.3`——差距几乎就是 `6Δx`，`Δx² = 0.0025` 那一项小到几乎看不见。

结论：**差距的来源就是"还带着 Δx 的那些项"**。它们不会消失，只会变小——所以式子只能"趋向"那个不含 Δx 的部分，不会"等于"它。

### 步骤 4：代码版（可选，走另一条路）

手算和代码只是两条路，代码不改变结论：

```
for dx in [0.2, 0.05, 0.02, 0.005]:
    print(dx, 12 + 6*dx + dx*dx)
```

**为什么这么做**：代码只是替你算数。真正要你自己回答的，还是"**趋向**和**等于**差在哪"。

### 步骤 5：所以"趋向"到底在说什么

> 取足够小的 `Δx`，**想让式子离 12 多近，就能让它多近**——但任何一次具体的取值，式子都不等于 12。

这就是 C 档题第 3 问要的答案。注意它和"等于 12"是**两句话**：
- "等于 12"说的是**某一行**的值是 12（表里没有这样一行）；
- "趋向 12"说的是**这些行整体往哪儿收**（表里每一行都在往 12 收）。
