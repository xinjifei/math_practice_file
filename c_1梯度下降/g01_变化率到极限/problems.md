## A 档 · 概念判定（不用算）

### 题 A1

"为什么不能让 `Δx` 等于 0"——答案很容易停在"因为式子会变成 `0/0`"。请再往下说一层：

`0/0` 为什么**不是答案**？它是"**不合法**"（有规则禁止），还是"**什么都没说**"（它没给你任何值）？

要求：不许用"不合法"三个字回答。用一句你自己的话，说清"如果你真的把 `Δx = 0` 代进去，你手上还剩什么"。

> 对应：**硬线 3** · 骨架第 4 步

### 题 A2

下面三句话，哪几句**不符合**"能把这件事说清楚"的标准？把不符合的改写成符合的（改写句里不许出现"无限"二字）。

1. "当 `Δx` 无限接近 0 时，平均变化率就变成了瞬时变化率。"
2. "让 `Δx` 取 1、0.1、0.01、0.001……一直变小，看平均变化率趋向哪个数，这个数就是它的瞬时变化率。"
3. "`Δx` 是无穷小的量，所以它既是 0 又不是 0。"

要求：除了指出哪几句不合格，还要说清**要害**——拿着不合格的那句话，你能不能算出哪怕一个数？它堵住了哪一步操作？

> 对应：**硬线 1** · 骨架第 3 步

## B 档 · 推导（要完整推，写全步骤，别跳步）

### 题 B1

**题面**：函数 `f(x) = x²`，当前点取 `x₀ = 3`。

1. 先写出"两个点之间"的**平均变化率**式子（`Δy/Δx` 的形式；两个点分别是 `3` 和 `3 + Δx`）。
2. 把它**化简**成"某个数 + 还带着 `Δx` 的项"的样子。
3. 列一张表：`Δx` 依次取 `1`、`0.5`、`0.1`、`0.01`，算出每个 `Δx` 对应的平均变化率。
4. 看着这张表，说出 `Δx` 不断变小时，平均变化率**趋向**哪个数。
5. 把第 4 步的结论**收口**：用 `lim` 记号，把这个"趋向"写成一行式子。

> 对应：**硬线 2** · 骨架第 1→2→3→5 步

### 题 B2

**题面**：还是 `f(x) = x²`，但**这次起点不取数**，就用字母 `x₀`。

1. 把另一个点写成 `x₀ + Δx` 的形式，写出这两个点之间的**平均变化率**。
2. 化简，直到式子只剩下"**一个不含 Δx 的部分** + **一些还带着 Δx 的部分**"。
3. 问：当 `Δx` 变小、趋向 0 时，那些"还带着 `Δx` 的部分"会怎么样？于是整个式子趋向**哪个含 `x₀` 的式子**？
4. 把 `x₀ = 3` 代回第 3 步的结论，看看是不是和 B1 第 4 步说出的那个数一样。

要求：
- **不引入任何新记号、新名字**（不要写 `f′(x)` 之类）——就老老实实写成"`x₀` 的式子"。
- 第 2 步是重点：你要能指着式子说清"这几项为什么会在 `Δx` 变小时退场"。

> 对应：**硬线 2** · 骨架第 2 步（符号化，不取数）+ 第 3 步（趋向）

## C 档 · 验算（手算或代码，任选一条路）

### 题 C1

用**你在 B1 第 2 步化简出来的那个式子**，把 `Δx` 继续往下取：`0.001`、`0.0001`、`0.00001`。

1. 手算：把三个 `Δx` 分别代进式子，写出三个结果。
   或者 代码：写几行，把 `Δx` 和式子的值一起打印出来。
2. 回答：表里最后那个值，离你要的"趋向值"还差多远？这个"还差一点点"，**能不能靠继续取更小的 Δx 彻底消掉**？
3. 回答：如果它消不掉、只会越来越小，那"**趋向**某个值"这句话准确的意思是什么？（注意：它和"**等于**那个值"是两句话。）

> 对应：**硬线 2** · 骨架第 3 步的收口
