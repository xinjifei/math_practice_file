# 第 47 天验收标准

## 体系定位 
- 所处模块：计算思维数学第 8/13 天。此前用收益、风险、算法复杂度建立了量化问题的度量视角；之后会进入因子预测力、Bootstrap、蒙特卡洛和时间序列。
- 今天把注意力从“一个数或一段序列”转到“对象之间的关系”：图用节点和边把关系显式化。
- 这块主要训练技术判断力与拆解能力：面对一个真实系统，先判断它能否建模为节点、边、方向和权重，而不是急着找算法或库。

## AI 分界线
- **归你（必须长在脑子里）**：判断什么是节点、什么是边；关系是否有方向、是否需要权重；识别包依赖为何需要是 DAG，以及如何用图的视角拆解关系问题。
- **可外包（概念要知道、实现交给 AI）**：NetworkX 的具体 API、画图参数，以及 DFS/BFS、最短路、中心性算法的实现细节。

## 硬线（不过不能结束，达标看学生笔记写没写到位）
- [ ] 能用自己的话把一个关系系统拆成“节点 + 边”，并清楚区分有向图、无向图、加权图；至少给出三个现实例子，说明各自的节点、边以及方向/权重选择。
- [ ] 能解释图不是“画几条线”，而是让关系可表示、可推断的模型；能说明度和介数分别在回答什么关系问题，及其不能单独决定的事。
- [ ] 能说明 Python 包依赖为什么应建模为 DAG（有向无环图），并把 Agent 调用链和 Attention 分别判断为哪类图，说明理由。

## 代码练习（少量，仅当硬线涉及动手写代码）
