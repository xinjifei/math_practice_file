# 第 42 天验收标准

## 体系定位
- 所处阶段：**模块四（计算思维数学）第 3/13 天**。40 定义了「一天赚百分之几」，41 把它换成「一年」这把统一的尺子，今天 42 把尺子换成**钱**——算术平均是算出来的那个数，几何平均是账户里实际剩下的。三天连起来是一条线：**收益率 → 年化 → 实际到手**。
- 今天这个概念在这个阶段中的角色：**评价标准的分水岭**。从今天起，"这个策略年化 15%"这句话必须先追问：算术还是几何？波动多大？后面 43（组合）、45（Sharpe）、46（最大回撤）都在追同一个问题——**同样的期望收益，怎样少受波动的罪**。43 的「神奇的事」就是：把波动降下来，几何收益悄悄涨上去。
- 和目标的关系：**技术判断力**。这是一类反复出现的判断："这个收益数字是怎么算的、它代表什么"。别人报 20% 你就要知道，如果波动是 40%，实际到手可能只有 12% 上下。

## AI 分界线
- **归你（必须长在脑子里）**：
  - 两种平均的公式、各自回答什么问题（算术 = 等权平均；几何 = 期末净值的 n 次方根）
  - **为什么几何才是实际赚到的**——钱是连乘的，不是连加的
  - 算术 ≥ 几何，且差距 **随波动增大**——"波动侵蚀收益"的方向和机制
  - 回本不对称：亏 X% 要涨 X/(1−X) 才能回本
  - 由此得出的判断规则：**评价策略看几何平均，不看算术平均**
- **可外包（概念要知道、实现交给 AI）**：
  - `几何 ≈ 算术 − σ²/2` 的泰勒展开推导（知道有这条近似、知道差距的量级就够）
  - numpy 里求几何平均的写法（`np.prod(1 + r) ** (1 / n) - 1`，记住模板即可）
  - 对数收益率下的等价写法 `exp(mean(log(1 + r))) - 1` 的具体代码

## 硬线（不过不能结束，达标看 note.md 写没写到位）
- [ ] 硬线1：**两种平均能算、能说出含义差在哪**——拿教材那组数算一遍：`+50%` 和 `−40%` → 算术平均 `(0.5 − 0.4)/2 = 5%`；几何平均 `√(1.5 × 0.6) − 1 = √0.9 − 1 ≈ −5.1%`。并且说清：几何平均 = **期末净值开 n 次方再减 1**，它回答的是"如果我每年都按同一个速度增长，这个速度是多少"，而这个速度连乘 n 次正好等于真实的期末净值
- [ ] 硬线2：**为什么几何才代表实际赚到的钱**——因为资金是**复利连乘**：两年下来账户是 `本金 × 1.5 × 0.6 = 0.9 倍`，亏了 10%。算术平均 5% 对应的那条"每年都恰好赚 5%"的假想路径（`1.05² = 1.1025`）**现实中不存在**。要能用自己的话把"连乘 → 开 n 次方 → 几何平均"这条链串起来，并指出这也是 Day 41「外推的年化收益 ≠ 实际收益」的同一个真相
- [ ] 硬线3：**波动侵蚀 + 回本不对称**——① 算术平均 ≥ 几何平均，**每年收益完全相同时取等号**；两者差距随波动增大（`σ` 越大差得越多，量级约 `σ²/2`）；② 亏 40% 后账户只剩 0.6，要涨回 1 需要 `1/0.6 − 1 ≈ 66.7%`——**跌得越深，回本要涨得越狠**；③ 由此得出判断：策略的"实际收益"要看几何平均，高波动的策略即使算术平均漂亮，几何平均也会被吃掉一块
