# m42 复利效应与几何收益率
> 对接收益率与实际得失
## 问题
> 从简单的例子切入引入几何收益率的必要性
```
本金：100
期1收益率：50%
期2收益率：-50%
```
- 这里算它的算数平均收益率：
```
(50% + (-50%))/ 2
 = 0%
```
- 发现结果为 0 也就是不赚不赔，但是如果带入实际值
```
100 * 1.5 * 0.5
 = 75
```
- 实际上赔了25，原因很简单：
> 算数平均假设每一期的本金不变，但是实际上每期的本金是上一期结束后的总资产。这个过程是乘性的，而非加性的
## 几何收益率
```
把实际上的期后资产用等式画出来
P_0 * (1 + r_1) * (1 + r_2)

现在想要的是 “固定” 数字就可以描述收益率，一个假想的收益率
从上面那个式子推
P_0 * (1 + g) * (1 + g)
 = P_0 * (1 + g)^2

方向明确了就是想要求这个g(但是要注意这个上面的那个指数是期数的意思，所以不是常数)
P_0 * (1 + g)^n = P_0 * (1 + r_1) * (1 + r_2) #刚才老方法
(1 + g)^n = (1 + r_1) * (1 + r_2)
1 + g = n√((1 + r_1) * (1 + r_2))
g = n√((1 + r_1) * (1 + r_2)) - 1
```
- 带入刚才的例子验算
```
>>> math.sqrt((1 + 0.5)*(1 + -0.5)) - 1
-0.1339745962155614
>>> 100 * (1 - 0.1339745962155614) **2
74.99999999999999
>>> 
```
- 和刚才手动连乘的结果对上了，所以获得最终公式：
$$
\boldsymbol{g=\sqrt[n]{\prod_{i=1}^n (1+r_i)} - 1}
$$
*Π = 连乘符号，大写的π，放到上面的例子展开就是：(1 + r_1) * (1 + r_2)*
> 总结一下，几何收益率g表达的是：如果按照这个收益率连乘，最后得到期末总资产，中的“这个收益率”，  
> 而且这里的结论还跟昨天的对上了：外推的年化收益率不等于实际的收益

## 不对称性
- 算数平均和几何平均永远都是 （算数≥几何），只有当每年的收益完全相等时两者才相等
```
算术：(0.2+0.2)/2 = 0.2
几何：√(1.2×1.2) −1 = 0.2
```
两者的差别随着变化的波动增加（比如第一个例子的 0% vs -13%）
- 回顾d40的一个结论：普通收益率涨跌不对称性。要回本就需要更高的收益率，回本的所需要的百分比 = X/(1−X) ，带到例子：
```
X = 0.5  # 跌幅50%
R = X / (1 - X)
R = 0.5 / (1 - 0.5)
R = 0.5 / 0.5
R = 1.0 = 100%

```
> 最后得出结论：1策略最后的复利收益要看几何平均，不能看算数平均。算数平均忽略了“为了回到原来的位置需要付出更多的努力”，这种努力的程度就取决于波动的幅度。这种现象也就是“波动侵蚀”
- 因为变化率波动导致的最后的差距与变化率的方差成正比。差值约等于σ²/2
