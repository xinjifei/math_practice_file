# 第 45 天验收标准

## 体系定位 
- 模块四「计算思维」第 6/13 天（40–52）。前面五天的路线是：收益率 → 年化 → 几何平均 → 组合风险 → 复杂度。今天第一次把「赚多少」和「抖多厉害」压成**一个数**。
- 角色：Day 40–44 分别量了收益、风险、复利、组合——但每个指标各说各话。Sharpe 是那个"把两件事合成一个可比标尺"的动作，也是后续判断策略好坏的通用语言。
- 后续直接依赖：Day 49 Bootstrap 的问题就是"你这个 Sharpe 是真本事还是运气"；Day 52 全流程复习会拿它当验收指标。
- 和目标的关系：技术判断力。不被高收益数字迷惑，能一眼看出"收益是靠水平还是靠胆子"——这是看任何策略报告都要用的第一层过滤。

## AI 分界线
- **归你（必须长在脑子里）**：公式里减 rf、除 σ 这两个动作各自在干什么；比较 Sharpe 的前提（同周期、同 rf、样本别太短）；Sharpe 高说明什么、**不**说明什么。
- **可外包（概念要知道、实现交给 AI）**：模拟收益序列的代码、年化换算的写法、画图代码。

## 硬线（不过不能结束，达标看 note.md 写没写到位）
- [ ] 硬线1：能用自己的话说清 Sharpe = (年化收益 − 无风险利率) / 年化波动 里**两个动作**各自的作用：为什么先减 rf（只算"多承担风险才多拿到"的那部分），为什么再除以 σ（把"赚的钱"折算成"每单位风险换来的钱"）。并能回答"只减不除会怎样"——两个年化都是 20% 的策略，凭什么一个更好。
- [ ] 硬线2：能说清 Sharpe 的比较前提和陷阱：参与比较的收益、波动、rf 必须同一时间尺度（都年化）、同一个 rf、样本不能太短；Sharpe 高 ≠ 绝对收益高；Sharpe 3+ 要么天才要么过拟合/运气好——这正是 Day 49 Bootstrap 要回头检验的东西。
- [ ] 硬线3：能用 A（年化 30%、σ=25%）vs B（年化 18%、σ=10%）这个案例讲清"高收益不等于高性价比"：B 的 Sharpe 更高，因为它的收益是靠水平赚的、A 的收益被波动吃掉了不少；并连回 Day 42 的结论（几何收益 = 算术平均 − 波动侵蚀），说清为什么 σ 小的人**实际到手**的复利反而可能更多。
