# 第 41 天验收标准

## 体系定位
- 所处阶段：**模块四（计算思维数学）第 2/13 天**。昨天（40）产出的是原料——"每天赚了百分之几"；今天把这个原料换到"年"这把尺子上。前一天是**定义**收益率，今天是**换算**收益率。
- 今天这个概念在这个阶段中的角色：**量纲转换器**。后面 42（复利/几何平均）、43（组合风险）、45（Sharpe）拿来做输入的全是年化后的数——Sharpe 的分子分母两个都是年化值。不年化，"两个月赚 8%"和"一年赚 15%"根本没法比，后面每一天的"好不好"都判断不了。
- 和目标的关系：**技术判断力**。这是一类反复出现的判断："这个数是怎么来的、能不能直接跟那个数比"。答不出来不是不会算，是手里没有统一标尺。

## AI 分界线 
- **归你（必须长在脑子里）**：
  - 两条换算公式，以及**为什么一个乘 N、一个乘 √N**——这是今天的全部重心
  - 为什么必须年化（不同天数、不同频率的序列，日频的数不能直接比）
  - 年化后的数怎么读：它是"按这个速度外推一年"，**不是**"每年实际赚这么多"
- **可外包（概念要知道、实现交给 AI）**：
  - `252` 这个常数的确切取值（美股惯例 252；A 股一年交易日约 242~244，用哪个不影响理解）
  - `std(ddof=1)` 里 `ddof` 怎么选（知道是"样本 / 总体"的修正就行）
  - 波动率期限结构（教材明确划掉：短期波动 ≠ 长期波动，年化只是近似）

## 硬线（不过不能结束，达标看 note.md 写没写到位）
- [ ] 硬线1：**两条公式 + 为什么必须年化**——能写出 `年化收益 ≈ μ_daily × 252`、`年化波动 ≈ σ_daily × √252`，并说清年化解决的是什么问题：**不同长度、不同频率的收益序列，直接比日频的数没有意义**（60 天的日均和 252 天的日均，量级本来就该差不多，但"这段时间到底赚了多少"差得远），年化把两者拉到同一把尺子上
- [ ] 硬线2：**一个乘 252、一个乘 √252 的推导**——这条是今天的核心。要说清：**能按天累加的是方差**（`σ²_年 ≈ σ²_日 × 252`），标准差是方差开根号，所以 `σ_年 ≈ √(σ²_日 × 252) = σ_日 × √252`；而**收益率本身是可加的**（昨天刚学的对数收益率可加性——这就是 × 252 的地基）。要**用数字推一遍**：`σ_daily = 1.5%` → 日方差 `0.000225` → ×252 = `0.0567` → 开根号 = `23.8%`
- [ ] 硬线3：**年化出来的数怎么读**——教材那组数（日均 `0.05%`、`σ_daily = 1.5%` → 年化收益 `12.6%`、年化波动 `23.8%`）要能说清各自是什么意思：`12.6%` 是**按这个日均速度外推一年**的期望值，不是"每年稳赚 12.6%"；`23.8%` 是这一年里起伏的尺度。**并且要说出这两个数放在一起的后果**：一年的波动（±23.8%）比一年的收益（12.6%）还大——单看某一年，亏钱完全正常。这一条是明天 Day 42 的接口

## 代码练习（少量）
- [ ] 练习1：**模拟 252 天，把两个数算出来，再看清它们的量级**
  - `rng.normal(loc=0.0005, scale=0.015, size=252)` 造一组日收益率（`loc`=均值、`scale`=标准差、`size`=天数）
  - 算 `returns.mean() * 252`（年化收益）和 `returns.std(ddof=1) * np.sqrt(252)`（年化波动）
  - 把 `returns.std(ddof=1)` 和 `returns.std(ddof=1) * np.sqrt(252)` 并排打出来——**看两者差了几倍**，这就是 `√252 ≈ 15.87` 这个系数
  - 再算"实际这一年"：`np.prod(1 + returns) - 1`（`np.prod` = 全部乘起来），和"日均 × 252"比，看差多少
