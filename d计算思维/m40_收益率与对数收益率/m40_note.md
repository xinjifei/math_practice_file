# m40 对数收益率与普通收益率
> 两种收益率
## 回顾与介绍
- 我事实上以及对普通收益率耳熟能详了，在这之前所说过的所有收益率都是普通收益率，它的公式是
$$
r_t=\frac{P_{t+1}}{P_t}-1
$$
*P = 单期价格，_t = 时间刻度，r = 收益率*
- 但是今天要介绍一种新的收益率：对数收益率
$$
r_t^{\log}=\ln\left(\frac{P_{t+1}}{P_t}\right)=\ln P_{t+1}-\ln P_t
$$
*最后一个相减的式子展示出了对数的可加性（相除 —— 相减）*
- 这种收益率计算方式在量化中拥有以下有益的特性

## 对数收益率的特性
> 展示这种收益率的特性
### 可加性
- 对于多期的收益率相加，直接等于这段时间的总对数收益率
```
# 初始价格 P0=100，P1=120，P2=156
#简单收益率：
r_{s1}=(120-100)/100=0.20
r_{s2}=(156-120)/120=0.30
直接相加：0.20+0.30=0.50
真实总简单收益率：(1+0.20)(1+0.30)-1=0.56
直接相加得到 0.50，不等于真实 0.56，相加无效。

#对数收益率
r_{l1}=\ln(120/100)≈0.1823
r_{l2}=\ln(156/120)≈0.2624
分段求和：0.1823+0.2624=0.4447
首尾一次性计算总对数收益：\ln(156/100)≈0.4447
两段结果完全相等。
```
### 涨跌对称性
- 对数收益率对于涨跌具有对称性
```
#价格路径：100 → 50 → 100
#简单收益率：
下跌段 r_{s,down}=(50-100)/100=-0.5
回本段 r_{s,up}=(100-50)/50=1.0
下跌 - 0.5，回本需要 + 1.0，正负数值大小不对称。

#对数收益率
下跌段 r_{l,down}=\ln(50/100)≈-0.6931
回本段 r_{l,up}=\ln(100/50)≈0.6931
二者绝对值相同，仅符号相反，涨跌对称。
```
### 分布对称性
- 相比于普通收益率，对数收益率更符合正态分布假设
```
#价格序列：100 →102 →99 →103 →101
#简单收益率序列：
(102-100)/100 = 0.02
(99-102)/102 ≈ -0.0294
(103-99)/99 ≈ 0.0404
(101-103)/103 ≈ -0.0194
简单收益率存在硬性下限 - 1，不可能低于 - 1，分布被截断。

#对数收益率序列：
ln(102/100)≈0.0198
ln(99/102)≈-0.0298
ln(103/99)≈0.0396
ln(101/103)≈-0.0198
对数收益率取值区间(-\infty,+\infty)，没有硬性下限，更贴近正态分布假设。
```
> 总结：从上面的例子中可以看得出来，对数收益率有着更好的统计学特性。但是这并不说明普通收益率就一无是处。总结下来两者的适用范围以及原因：  
- 对数收益率：他因为上面的各种数学特征，更适合做量化的中间计算，数据分析。
- 普通收益率：它具有更强的人类可读性，因此用于日常账单与交流（听说还有一些特殊的算法也基于普通收益率）
## 小波动重合特性
- 通过计算，会发现在变化波动较小的范围中，对数收益率与普通收益率几乎重合，而随着波动增大，这种重合也会逐渐趋于分化
$$
\boldsymbol{\ln(1+r_s) \approx r_s}
$$
```
#案例 A：简单收益率 r_s=50\%=0.50简单收益率：r_s=0.50
对数收益率：r_l=\ln(1+0.50)=\ln(1.5)\approx0.4055
差值：r_s - r_l = 0.50 - 0.4055 = 0.0945
#案例 B：简单收益率 r_s=1\%=0.01简单收益率：r_s=0.01
对数收益率：r_l=\ln(1+0.01)=\ln(1.01)\approx0.00995
差值：r_s - r_l = 0.01 - 0.00995 = 0.00005
```
> 通过计算可以看出这种波动小重合，波动大分化的趋势
