# m46最大回撤
> 一个策略曾经跌的最狠的一次

## 基础概念
- 一个策略再好，都会有亏的时候。在实际场景中怎么量化“一个策略亏过最狠的一次”，需要使用“最大回撤”的概念

落到实处也就是一个策略所产出的累计净值曲线中最大的跌幅，因为是跌幅一般用所以用负数百分比.   
有一个常见的坑：最大回撤就是最终亏损。实际上并不是这样，累计净值曲线的左边比右边低，不等于它的中间不会跌，它很有可能是起伏式的。  
这种起伏常常致命在真实场景中只能看到“伏”看不到前面的“起”，这样对信心很有打击。  

伪代码：
```python
list = 累计净值曲线
def MDD_cal(V_list)
    D_list = []
    for v in V_list:
        # 先计算历史的最高峰(滚动峰值)
        p = 以当前天为起点到第一天中最大值
        # 再计算今天的净值，相比此前达到过的最高点，跌了百分之多少
        D = (v - p)/p
        # 添加到回撤列表
        D_list.append(D)

    # 找最大回撤
    MDD = min(D_list)
    return MDD
```
但是简单的最大回撤没有时间信息，也就是同样的“资产减半过”，有可能是一周之间发生的事，也有可能是也个月发生的事，只看mdd看不出来这层区别

## 经典现象
- 一只Sharpe很大同时最大回撤也很大的股票（对应一个策略，股票本身不存在累计净值曲线），可能仍然难以持有  
这是因为这有可能是一个收益和风险都不错的累计净值曲线，但是在这同时它在某一段跌的很厉害。而对于没有上帝视角的投资者，在最大回撤处看到的就是完全下跌的资产。这种情况就被称之为“难以持有”。  
重点在于，假如累计净值曲线的收益和风险都不错，但是这不能完全说明它的最大回撤很小。两者（sharpe和最大回撤）完全有可能同时大
