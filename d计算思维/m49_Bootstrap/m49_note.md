- bootstrap最有特点的“有放回”操作为什么是必须的？因为目的是模拟“如果还按照当时的情况，数据会怎么分布”，而不想要“按照新顺序重新排列数据”。重新排列后样本统计量不会变，但是抽样才能观察出变化的波动

## 特性
- bootstrap因为直接从样本中抽样，所以不用强制假设小样本符合正态分布
- bootstrap得出的结论是“这个样本下的统计量有多不稳定”，要直观理解这一点可以做一个最极端的思想实验：  
这是两个策略的Sharpe列表，他们的均值都是10
```
# 两个列表长度都为10
A = [0,0,...0,100]
B = [10,10,...10]
```
*脚本图片：./m49_bootstrap_thought_experiment.png*
可以看到如果说要从图中得到的结论是“这个样本下的统计量有多不稳定”，那么A远远没有B稳定

- 这个结论不能说明“策略一定有效”，也不等于“这个策略以后就一定会如此”，因为bootstrap揭示的内容是通过过去得出的，不能够一定说明未来


## 指标
- 有三个能从bootstrap分布中得到的指标

1. 均值：bootstrap列表的均值，理论上等于原始数据集均值
2. 中位数：把bootstrap列表按照大小排序，取中间的值。它和均值的区别在于均值会收到极值的影响，而中位数看的是排序
3. 分位数：这个复杂一点，但是同时也很重要。同样拿排序后的bootstrap列表，现在需要找到它们在列表中占前2.5%的位置，以及占95%的位置。然后得到这个区间中值的范围，这个范围叫“分位数区间”

它们分别解释：
- 重抽样统计量的平均水平是多少
- 重抽样统计量的中间位置在哪里？
- 重抽样统计量主要分布在哪个范围？
