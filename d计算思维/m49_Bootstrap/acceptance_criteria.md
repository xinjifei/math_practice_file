# 第 49 天验收标准

## 体系定位
- 所处模块：计算思维数学，第 10 / 13 天。第 48 天先判断因子是否有预测信号；今天进一步面对现实限制：样本少时，指标本身有多大不确定性？
- Bootstrap 把一组有限观测反复重抽样，得到统计量可能波动的经验分布，是后续蒙特卡洛模拟与量化检验流程中的抽样直觉基础。
- 它为技术判断力添上一块：面对一个看起来不错的 Sharpe、均值或中位数，先判断它在样本变化下是否稳定，而不是把单次计算结果当结论。

## AI 分界线
- **归你（必须长在脑子里）**：Bootstrap 的输入是一份已有样本；每次必须有放回地抽取同样多的观测；反复计算同一个统计量后，得到的是该统计量在这份数据下的经验分布，而非凭空制造新信息。
- **可外包（概念要知道、实现交给 AI）**：用 NumPy 批量重抽样、选择重复次数、计算分位数区间、绘制直方图与格式化输出。

## 硬线（不过不能结束，达标看学生笔记写没写到位）
- [ ] 能用自己的话说明 Bootstrap 的完整链条：从原样本有放回地抽同样数量的样本，重复计算目标统计量，最终看统计量的经验分布；并说明“有放回”为什么是必要条件。
- [ ] 能判断 Bootstrap 回答的是“这份有限样本下统计量有多不稳定”，而不是“策略一定有效”或“未来必然如此”；知道它适合不愿强行假设正态分布的小样本场景。
- [ ] 能解释 Bootstrap 分布中均值、中位数和分位数区间各在表达什么，并据此判断一个看似很好的单次 Sharpe 或平均收益是否值得谨慎对待。
