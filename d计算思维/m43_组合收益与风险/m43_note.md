# m43 组合收益率与风险
> 多个资产得出的收益率与风险

## 推导
### 组合收益率
```
收益率 = R
组合收益率 = w_1*R_1 + w_2*R_2
(w = 权重，投入了总数的百分之多少（float）)
```
$$
R_p = w_A R_A + w_B R_B
$$
### 组合风险（标准差）
```
组合收益率减去期望
R_p − µ_p = w_1(R_1 − µ1) + w_2(R_2 − µ_2)
带入方差公式
sigma_p^2 = ∑[(w_1(R_1 - µ_1) + w_2(R_2 - µ_2))^2]
展开
∑[w_1^2(R_1 - µ_1)^2
+ w_2^2(R_2 - µ_2)^2
+ 2*w_1*w_2(R_1 - µ_1)(R_2 - µ_2)]

化简
sigma_p^2 = 
w_1^2*sigma_1^2 + w_2^2*sigma_2^2 + 2*w_1*w_2 COV(R_1,R_2)
```
最后得到公式（最后面的协方差变相关系数）
$$
\sigma_p^2=
w_A^2\sigma_A^2+
w_B^2\sigma_B^2+
2w_Aw_B\rho_{AB}\sigma_A\sigma_B
$$

- 根据推导可以得出公式的三个项的含义
1. 前两个项：两个资产各自带进组合的风险
2. 第三个项：它们之间的波动怎样互相影响，这种“互相”体现在p（相关系数）上

## 相关系数对组合风险的影响
*对比使用加权平均风险 = w_1*sigma_1 + w_2*sigma_2*
- 当p < 1时组合风险只会低于加权平均风险  
从直觉上理解的话：只要小于1，两者必定存在相互抵消部分
- p = 1时两者相等，不存在上面说到的“抵消”
- p = -1时。它们的收益波动完全反向。理论上如果配置的权重恰好让两  
边的波动幅度相互抵消，组合的风险就能降到 0。
- p = 0 ，从式子上一眼看出来
```
加权平均风险 = w_1*sigma_1 + w_2*sigma_2
组合风险 = √(w_1^2*sigma_1^2 + w_2^2*sigma_2^2)
# 组合风险的第三个项直接变成零消失了
```
- 从几何角度理解：直角三角形ab的和，肯定大于斜边c（借用勾股定理变量名）

## 结论
- 收益不变，但是组合收益率总是会使波动更小。也就是说
> 分散化可以使收益率不变的同时下降低波动
- m42（昨天），学到过：复利收益率会考虑到波动带来的“侵蚀”  
而分散化可以降低波动，所以
> 分散化可以降低波动，进而提升复利收益率
